📖 GitHub Setup Guide

5000 NSE stocks ka automatic daily scan chalu karne ke liye step-by-step (10 minute ka kaam hai)
1

GitHub par Account aur Repo banao

• GitHub.com par jao → Sign up (agar account nahi hai)
• New Repository par click karo
• Repo name: monthly-zone-scan
• Public select karo (important! nahi to dashboard data nahi utha payega)
• "Add a README file" ko check karo → Create repository

2

Repo mein Folder Structure banayo

Repo khul ke, ye files ek-ek karke create karo (Add file → Create new file):

monthly-zone-scan/ ├── scanner.py # main scanner script ├── requirements.txt # Python dependencies ├── .github/ │ └── workflows/ │ └── daily_scan.yml # auto-run at 9:30 PM IST └── reports/ # yahan daily CSV banegi
3

requirements.txt

Yeh content paste karo:

yfinance>=0.2.31 pandas>=2.0.0 numpy>=1.24.0
4

scanner.py (Main GTZ Zone Scanner)

Neeche "Download Scanner Files" button se ready-made Python script download karo aur upload kar do. Script mein GTF D&S logic already programmed hai.

5

GitHub Actions Workflow

Yeh file .github/workflows/daily_scan.yml banayo — yeh har din raat 9:30 PM IST ko automatic scanner chalaayega:

name: Daily GTF Zone Scan on: schedule: # 9:30 PM IST = 16:00 UTC - cron: '0 16 * * 1-5' # Mon-Fri workflow_dispatch: # manual run bhi kar sakte ho jobs: scan: runs-on: ubuntu-latest steps: - uses: actions/checkout@v4 - uses: actions/setup-python@v5 with: python-version: '3.11' - run: pip install -r requirements.txt - run: python scanner.py - uses: stefanzweifel/git-auto-commit-action@v5 with: commit_message: 'auto: daily GTF zone scan' file_pattern: 'reports/*.csv'
6

Pehla Manual Run

• GitHub repo mein Actions tab par jao
• Left side se "Daily GTF Zone Scan" select karo
• Run workflow button dabao → pehla scan chalu ho jayega (5-10 min lagenge)
• Poora hone par reports/ folder mein zone_report_YYYY-MM-DD.csv file ban jayegi

7

Dashboard mein Repo Connect

Dashboard mein index.html mein line ~567 par ye line hai:
const GH_REPO="heartaltafhussain-lgtm/monthly-zone-scan";
Isko apne repo se replace karo: const GH_REPO="tumhara_username/monthly-zone-scan";
Phir Refresh button dabao — aapki repo se live data aane lagega!
